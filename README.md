# gabrielguedesmath.github.io

Personal academic page of Gabriel Guedes (UFRPE, Recife, Brazil).

https://gabrielguedesmath.github.io

Languages: English (`/`), Português (`/pt/`), Español (`/es/`), Français (`/fr/`).

The four pages are generated. Edit `_src/page.html` (English and Portuguese) and `_src/i18n.json` (Spanish and French), then run `python3 _src/build.py`.
